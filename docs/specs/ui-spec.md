## 1. デザイン原則

### 1.1 Tempo AI 固有の原則

| 原則                   | 実践方法                                   |
| ---------------------- | ------------------------------------------ |
| 情報の優先順位を明確に | ホーム画面では「今日のアドバイス」を最優先 |
| データを「感じさせる」 | スコアだけでなく状態を言葉で表現           |
| 押し付けない、寄り添う | 「〜してみてください」という柔らかい語尾   |
| 継続を支える           | 今日のトライで新しい発見                   |

### 1.2 適用する UX 心理原則

- **Doherty Threshold**: 0.4 秒以内の反応
- **Labor Illusion**: AI 分析中を明示し価値を感じさせる
- **Progressive Disclosure**: 詳細は「もっと見る」で展開

### 4.2 エネルギーバッテリー表示

**目的**: ユーザーが「今日は無理していい日か、休むべき日か」を 0.1 秒で判断できるようにする

| 要素               | 内容                                        |
| ------------------ | ------------------------------------------- |
| エネルギー値       | HRV スコア（0-100）をパーセント表示         |
| プログレスバー     | スコアに応じた塗りつぶしゲージ              |
| AI コメント        | スコアに応じた一言コメント                  |
| 色                 | 状態カラー（セクション 2.2 参照）に準拠     |

#### エネルギーコメント例

| スコア範囲 | コメント例                               |
| ---------- | ---------------------------------------- |
| 80-100     | 「今日は絶好調ですね！」                 |
| 60-79      | 「いいコンディションです」               |
| 40-59      | 「無理せずペース配分を」                 |
| 20-39      | 「今日は休息を優先しましょう」           |
| 0-19       | 「しっかり休んでくださいね」             |

#### スペーシング

| 要素                           | 値   |
| ------------------------------ | ---- |
| パーセント表示フォントサイズ   | 32pt |
| AI コメントフォントサイズ      | 14pt |
| プログレスバー高さ             | 8pt  |
| カード内パディング             | 16pt |

### 4.3 スペーシング

| 要素間                        | 値   |
| ----------------------------- | ---- |
| ヘッダー → エネルギー         | 16pt |
| エネルギー → アドバイス       | 20pt |
| アドバイス → トライ           | 24pt |
| 画面端からの余白              | 16pt |

```
│                                     │
│    リズム安定度                      │
│    ●●●○○ 良好                      │
│    「3日連続で安定」                 │
├─────────────────────────────────────┤
│    3つの指標                         │
│           HRV 72ms（結果）           │
│          /        \                 │
│       睡眠        歩数               │

│     （回復）     （活動）             │

│    今日の見立て                      │
│    マサさん、今朝の自律神経の...      │
└─────────────────────────────────────┘
```

### 5.2 24 時間サークル図

| 要素             | 内容                                  |
| ---------------- | ------------------------------------- |
| 外周             | 過去 7 日間の就寝・起床時刻をプロット |
| 睡眠帯           | 昨夜の睡眠時間を塗りつぶしで表示      |
| **現在時刻カーソル** | 円グラフ上に現在位置を示すアイコン   |
| **ゾーン色分け** | 集中ゾーン/休憩ゾーンを視覚的に区別   |
| 中央上部         | HRV 値（ms）を大きく表示              |
| 中央下部         | 7 日平均との差分（▲+9% など）         |
| 下部テキスト     | 就寝時刻・起床時刻                    |

#### 現在時刻カーソル

**目的**: 「今、自分がどこにいるか」を強調し、1 日のペース配分を把握しやすくする

| 要素           | 仕様                                      |
| -------------- | ----------------------------------------- |
| アイコン       | SF Symbol `sun.max.fill`（日中）または `moon.fill`（夜間） |
| 位置           | 現在時刻に対応する角度に配置              |
| 更新頻度       | 毎分更新                                  |
| サイズ         | 24pt                                      |
| 色             | Primary (#7CB342)                         |

#### 角度計算

```swift
// 時刻を角度に変換（0:00 = -90度、6:00 = 0度、12:00 = 90度、18:00 = 180度）
func angleForTime(_ date: Date) -> Double {
    let hour = Calendar.current.component(.hour, from: date)
    let minute = Calendar.current.component(.minute, from: date)
    let totalMinutes = Double(hour * 60 + minute)
    return (totalMinutes / 1440.0) * 360.0 - 90.0
}
```

#### 集中ゾーン/休憩ゾーンの色分け

**目的**: 「今は集中すべき時間帯か、休憩すべき時間帯か」を視覚的に把握

| ゾーン     | 時間帯           | 色                          | 透明度 |
| ---------- | ---------------- | --------------------------- | ------ |
| 集中ゾーン | 9:00-12:00       | Primary (#7CB342)           | 0.15   |
| 集中ゾーン | 14:00-17:00      | Primary (#7CB342)           | 0.15   |
| 休憩ゾーン | 12:00-14:00      | Secondary (Warm Beige)      | 0.2    |
| 睡眠ゾーン | 22:00-6:00       | 濃いグレー (#4A4A4A)        | 0.3    |

※ ゾーンはサークル図の外周に薄い弧として表示

### 5.3 リズム安定度表示

| 条件                             | ステータス | 説明文                                 |
| -------------------------------- | ---------- | -------------------------------------- |
| スコア ≥70 かつ 3 日以上連続安定 | 良好       | 「{N}日連続で安定 → 回復効率アップ中」 |
| スコア ≥70 かつ 連続 2 日以下    | 良好       | 「リズムが整っています」               |
| スコア 50-69                     | やや不安定 | 「就寝時刻にばらつきがあります」       |
| スコア<50                        | 不安定     | 「リズムの乱れが回復を妨げています」   |

## 8. インタラクション

### 8.1 画面遷移

| 遷移の種類       | アニメーション       |
| ---------------- | -------------------- |

- **ボタン**: タップ時に色が少し濃くなる
- **カード**: タップ時に少し縮む（scale: 0.97）
- **応答速度**: 0.4 秒以内

## 9. トーン・表現方法

### 9.1 キャラクター

「年上の落ち着いた優しいお姉さん」

- 温かく励ましつつ根拠を示す
- ニックネームで呼びかける
- 押し付けず、提案する

### 9.2 語尾パターン

| パターン           | 例                                       |
| ------------------ | ---------------------------------------- |
| 〜ですね           | 「良質な睡眠が取れましたね」             |
| 〜してみてください | 「深呼吸を 3 回してみてください」        |
| 〜するといいですね | 「23 時までに就寝できるといいですね」    |
| 〜かもしれませんね | 「少し疲れを感じやすいかもしれませんね」 |

※ 詳細なトーンガイドラインは [ai-prompt-spec.md](./ai-prompt-spec.md) を参照

## 10. アクセシビリティ

### 10.1 VoiceOver 対応

- 全画面がナビゲート可能
- 適切なラベルとヒント

### 10.2 Dynamic Type 対応

- スケーラブルフォント使用
- 最小倍率: 0.7

### 10.3 カラーコントラスト

- テキストは常にプライマリカラー
- ステータス色は背景とセットで使用
