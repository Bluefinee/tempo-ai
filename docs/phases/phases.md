## Part D2: サーカディアンリズム画面リニューアル

### Phase 12.5: サーカディアンリズム画面リニューアル 🔜

**目的**: Phase 12で実装した画面を新デザインにリニューアル

**主な変更**:
- 「三角形」構成を廃止
- 24hサークル（Solar Sync）をトップに配置
- 指標リストをフラットに表示（HRV→睡眠→歩数→日光→体温）
- 日光浴（Time in Daylight）指標を追加
- 手首皮膚温（Wrist Temperature）指標を追加（対応機種のみ）
- スコア算出ロジックをドメインモデルに凝集

**新しい画面構成**:
1. 24hサークル（Solar Sync）
   - 外周: 太陽の動き（日の出・日の入り）
   - 内周: ユーザーの体内時計（体温リズム）
   - 現在地マーカー + 状態メッセージ
   - ズレ警告（該当時のみ）

2. 指標リスト（フラット表示）
   - HRV: 値 + 7日平均比較 + 5段階ゲージ + コメント
   - 睡眠: 時間 + 5段階ゲージ + コメント
   - 歩数: 値 + 5段階ゲージ + コメント
   - 日光浴: 時間 + 警告（不足時）+ 5段階ゲージ
   - 体温: ステータス + コメント（対応機種のみ）

3. 今日の見立て（insight）

**完了条件**:
- [ ] 24hサークルが正しく描画される
- [ ] 現在地マーカーが毎分更新される
- [ ] 5つの指標がフラットリストで表示される
- [ ] 日光浴データがHealthKitから取得できる
- [ ] 体温データが対応機種で取得できる（非対応機種は非表示）
- [ ] スコア算出ロジックがドメインモデルに凝集されている
- [ ] insightが表示される
- [ ] 三角形構成のコードが削除されている
