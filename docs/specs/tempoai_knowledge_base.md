## 1. サーカディアンリズムの基礎

### 定義

サーカディアンリズム（概日リズム）とは、生物が約24時間周期で繰り返す生理的なリズムのこと。睡眠と覚醒のサイクル、体温の上下、ホルモン分泌量の変動などを司る。

### メカニズム

| 要素 | 説明 |
|------|------|
| **司令塔** | 脳の視床下部にある「視交叉上核（SCN）」が体内時計の司令塔。時計遺伝子がタンパク質の生成・分解のループを作り、リズムを生み出す |
| **同調因子（光）** | 目の網膜にある特殊な神経細胞（メラノプシン含有）が朝の光（特に青色光成分）を感知し、SCNに信号を送ることで体内時計がリセットされる |
| **末梢時計** | 肝臓、腸、筋肉などの臓器にも存在。「食事の時間」によってリセットされ、全身のリズムが脳の中枢時計と揃う |

### ホルモンとの関係

サーカディアンリズムはホルモン分泌と密接に関係しており、**朝の行動が夜の睡眠を決定づける**。

#### 朝のスイッチ
- 強い光を浴びると、睡眠ホルモン「メラトニン」の分泌が抑制
- 体が「朝が来た」と認識
- ストレスホルモン「コルチゾール」の分泌が増加
- 血圧や血糖を上げて体を活動モードに切り替え

#### 夜のスイッチ
- 朝の光刺激によって、SCNは**約14〜16時間後**に再びメラトニンを分泌するようタイマーをセット
- 夜になると自然な眠気が訪れる

### リズムの乱れと不調

| 症状カテゴリ | 具体例 |
|-------------|--------|
| **睡眠障害** | 寝付きが悪い、夜中に目が覚める、朝起きられない、日中の眠気 |
| **身体症状** | 疲労感、冷え性（交感神経優位による血管収縮） |
| **精神症状** | メンタルの不安定さ、不定愁訴 |

## 2. 自律神経のバランスとHRV

### 自律神経の役割

自律神経は、体を活動させる「交感神経」とリラックスさせる「副交感神経」から成り、**パソコンのOSのような役割**を果たす。

| 神経 | モード | 優位になる時間帯 |
|------|--------|-----------------|
| **交感神経** | 活動・戦闘モード | 日中 |
| **副交感神経** | リラックス・回復モード | 夜間 |

### HRV（心拍変動）とは

HRVは心拍の間隔のゆらぎを示す指標で、自律神経のバランスを客観的に測定できる。

| HRV状態 | 意味 |
|---------|------|
| **低い** | 交感神経が優位（過緊張・ストレス状態） |
| **高い** | 副交感神経が優位（リラックス状態） |

### スイッチングの重要性

健康な状態では、日中は交感神経、夜間は副交感神経へと**スムーズに切り替わる**。この「スイッチング」がうまくいかないと：

- 夜中に目が覚める
- 睡眠の質が低下
- 日中の不調（だるさ、イライラ）

## 3. Apple Watchで確認すべきデータ

### 最重要指標

#### 1. 手首体温（皮膚温）
**サーカディアンリズム確認の最も強力な指標**（Series 8 / Ultra以降）

- 人間の深部体温はサーカディアンリズムに従って変動
- 正常なリズム：寝ている間は下がり、目覚める前に上がり始める
- チェックポイント：就寝中にグラフが安定して下がっていれば正常

#### 2. HRV（心拍変動）
**自律神経バランスの客観的指標**

- 日中は交感神経優位（低HRV傾向）
- 夜間は副交感神経優位（高HRV傾向）
- このスイッチングが適切に行われているかを確認

#### 3. 睡眠ステージ
**リズムの規則性を確認**

- 就寝・起床時間が毎日一定かどうか
- 正常なパターン：寝付いてから早い段階で「深い睡眠」→ 朝方にかけて「レム睡眠」増加
- 就寝時間がバラバラだとこの波形が崩れる

### 補助指標

#### 4. 日光の下で過ごした時間
**サーカディアンリズムリセットの確認**（SE第2世代、Series 6以降）

- 午前中に日光を浴びているかが重要
- 日中の光摂取量が極端に少ない → 夜の睡眠の質低下、リズム崩れ

#### 5. 安静時心拍数
**全体的なコンディション指標**

- ベースラインからの変動を追跡
- 急激な上昇は疲労やストレスの兆候

## 4. データの相関分析

### Apple Watch単体で見える「結果」

| データ | わかること |
|--------|-----------|
| HRV | 自律神経の状態（今どうなっているか） |
| 睡眠 | 休息の質と量 |
| 歩数・運動 | 活動量 |

### CGM（将来的な連携候補）で見える「原因」

CGMは血糖のリアルタイム指標であり、Apple Watchデータと組み合わせることで**「なぜ」その状態になったか**を読み解ける。

| 発見できる相関 | 説明 |
|---------------|------|
| HRVが落ちている日 ↔ 血糖値が高く揺れている日 | 代謝ストレスと自律神経の連動 |
| 同じ食事でも食べる順番 → 血糖の急上昇差 | 行動の微差が身体反応を変える |
| 前日の夕食の時間 → 翌朝のHRV | 食事タイミングと回復の関係 |
| 食後の軽い散歩 → 血糖がなだらかに | 運動の血糖安定効果 |

> **設計メモ**: CGM連携は将来的な拡張として検討。現時点ではApple Watchデータのみで「結果」を把握し、AIが「原因の仮説」を提示するアプローチ。

## 5. アルゴリズム設計への示唆

### スコアリングロジック

#### 自律神経スコア計算の考え方

1. **ベースライン確立**: 直近30日のHRV平均を算出
2. **日次比較**: 当日のHRVとベースラインを比較
3. **正規化**: 0〜100のスコアに変換
4. **補正要素**: 睡眠の質、活動量なども加味

#### リズム評価の考え方

1. **就寝・起床時間の一貫性**: 標準偏差で規則性を評価
2. **睡眠ステージのパターン**: 深い睡眠 → レム睡眠の正常な移行
3. **手首体温の変動**: 夜間の体温低下パターン

### AIインサイト生成のコンテキスト

Claudeに渡すべき情報：

```
1. 当日の客観データ
   - HRV（値 + ベースライン比）
   - 睡眠時間・質
   - 睡眠ステージ分布
   - 安静時心拍数

2. 時系列コンテキスト
   - 過去7日間の要約
   - トレンド（改善/悪化/維持）

3. 環境データ
   - 気圧（傾向）
   - 天気
   - 日の出/日の入り時刻

4. 主観データ（ユーザー入力）
   - 今の気分（5段階）
```

### 相関気づきの生成

Claudeに分析させる相関パターン例：

- 「睡眠時間が7時間を超えた日は、スコアが平均10ポイント高い」
- 「就寝時刻が23時以前の日は、深い睡眠の割合が20%増加」
- 「気圧が急低下した翌日は、HRVが平均15%低下する傾向」

## 7. 参照データソースと精度

### HealthKit から取得するデータ

| データタイプ | 用途 | 精度の考慮 |
|-------------|------|-----------|
| `HKQuantityType.heartRateVariabilitySDNN` | 自律神経スコア | 夜間・安静時の値が最も信頼性高い |
| `HKCategoryType.sleepAnalysis` | 睡眠ステージ | Apple Watch装着が前提 |
| `HKQuantityType.appleSleepingWristTemperature` | 体温変動 | Series 8以降のみ |
| `HKQuantityType.restingHeartRate` | 基礎心拍数 | 日次のトレンド確認に使用 |
| `HKQuantityType.stepCount` | 活動量 | 運動との相関分析に使用 |
| `HKQuantityType.timeInDaylight` | 日光暴露 | リズムリセットの確認 |

### WeatherKit から取得するデータ

| データタイプ | 用途 |
|-------------|------|
| 気圧（傾向含む） | 体調への環境影響評価 |
| 天気 | UI演出 + コンテキスト |
| UV指数 | 屋外活動の推奨判断 |
