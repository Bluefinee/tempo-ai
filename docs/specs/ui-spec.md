## 1. デザイン原則

### 1.1 Tempo AI 固有の原則

| 原則                   | 実践方法                                   |
| ---------------------- | ------------------------------------------ |
| 情報の優先順位を明確に | ホーム画面では「今日のアドバイス」を最優先 |
| データを「感じさせる」 | スコアだけでなく状態を言葉で表現           |
| 押し付けない、寄り添う | 「〜してみてください」という柔らかい語尾   |
| 継続を支える           | 今日のトライで新しい発見                   |

### 1.2 適用する UX 心理原則

- **Doherty Threshold**: 0.4 秒以内の反応
- **Labor Illusion**: AI 分析中を明示し価値を感じさせる
- **Progressive Disclosure**: 詳細は「もっと見る」で展開

### 4.2 エネルギーバッテリー表示

**目的**: ユーザーが「今日は無理していい日か、休むべき日か」を 0.1 秒で判断できるようにする

| 要素               | 内容                                        |
| ------------------ | ------------------------------------------- |
| エネルギー値       | HRV スコア（0-100）をパーセント表示         |
| プログレスバー     | スコアに応じた塗りつぶしゲージ              |
| AI コメント        | スコアに応じた一言コメント                  |
| 色                 | 状態カラー（セクション 2.2 参照）に準拠     |

#### エネルギーコメント例

| スコア範囲 | コメント例                               |
| ---------- | ---------------------------------------- |
| 80-100     | 「今日は絶好調ですね！」                 |
| 60-79      | 「いいコンディションです」               |
| 40-59      | 「無理せずペース配分を」                 |
| 20-39      | 「今日は休息を優先しましょう」           |
| 0-19       | 「しっかり休んでくださいね」             |

#### スペーシング

| 要素                           | 値   |
| ------------------------------ | ---- |
| パーセント表示フォントサイズ   | 32pt |
| AI コメントフォントサイズ      | 14pt |
| プログレスバー高さ             | 8pt  |
| カード内パディング             | 16pt |

### 4.3 スペーシング

| 要素間                        | 値   |
| ----------------------------- | ---- |
| ヘッダー → エネルギー         | 16pt |
| エネルギー → アドバイス       | 20pt |
| アドバイス → トライ           | 24pt |
| 画面端からの余白              | 16pt |

### 5.2 24h サークル（Solar Sync）

**コンセプト**: 体内時計と太陽（外部時間）の「同期（Sync）」を可視化

| 要素           | 内容                                                   |
| -------------- | ------------------------------------------------------ |
| 外周リング     | 太陽の動き（日の出〜日の入りを明るく、それ以外を暗く） |
| 内周リング     | ユーザーの体内時計（体温リズムに基づく推定）           |
| 現在地マーカー | SF Symbol `sun.max.fill`（日中）/ `moon.fill`（夜間）  |
| 状態メッセージ | 「覚醒のピークです」「リラックスタイムです」など       |
| ズレ警告       | 体内時計と外部時間のズレが 1 時間以上ある場合に表示    |

#### 色指定

| 要素           | 色                        |
| -------------- | ------------------------- |
| 外周（日中）   | Primary (#7CB342) 透明度0.3 |
| 外周（夜間）   | Gray 透明度0.2            |
| 内周           | Primary (#7CB342) 透明度0.5 |
| 現在地マーカー | Primary (#7CB342)         |
| ズレ警告       | Orange (#FF9800)          |

#### 角度計算

```swift
// 時刻を角度に変換（0:00 = -90度、6:00 = 0度、12:00 = 90度、18:00 = 180度）
func angleForTime(_ date: Date) -> Double {
    let hour = Calendar.current.component(.hour, from: date)
    let minute = Calendar.current.component(.minute, from: date)
    let totalMinutes = Double(hour * 60 + minute)
    return (totalMinutes / 1440.0) * 360.0 - 90.0
}
```

### 5.3 指標リスト

| 指標   | アイコン | 表示内容                                        |
| ------ | -------- | ----------------------------------------------- |
| HRV    | 💓       | 値(ms) + 7 日平均比較(▲/▼%) + ゲージ + コメント |
| 睡眠   | 😴       | 時間 + ゲージ + コメント                        |
| 歩数   | 🚶       | 値 + ゲージ + コメント                          |
| 日光浴 | ☀️       | 時間 + 警告アイコン(不足時) + ゲージ + コメント |
| 体温   | 🌡️       | ステータス + ゲージ + コメント（対応機種のみ）  |

#### 5 段階ゲージの色

| レベル | 表示  | 色                |
| ------ | ----- | ----------------- |
| 5      | ●●●●● | Primary (#7CB342) |
| 4      | ●●●●○ | Primary (#7CB342) |
| 3      | ●●●○○ | Yellow (#FFC107)  |
| 2      | ●●○○○ | Orange (#FF9800)  |
| 1      | ●○○○○ | Red (#F44336)     |

#### 体温の表示条件

- Apple Watch Series 8 / Ultra 以降のみ対応
- 非対応機種では項目自体を非表示
- 5 晩以上のデータが必要（初期は「データ収集中」と表示）

### 5.4 今日の見立て

- 因果関係を明示した AI コメント（3-5 文）
- 詳細は [ai-prompt-spec.md](./ai-prompt-spec.md) セクション 4 を参照

### 5.5 スペーシング

| 要素間                 | 値   |
| ---------------------- | ---- |
| サークル上下パディング | 24pt |
| サークルとズレ警告     | 16pt |
| ズレ警告と指標リスト   | 20pt |
| 各指標間               | 16pt |
| 指標リストと見立て     | 24pt |

| ---------------- | -------------------- |

### 8.2 タップフィードバック

- **ボタン**: タップ時に色が少し濃くなる
- **カード**: タップ時に少し縮む（scale: 0.97）
- **応答速度**: 0.4 秒以内

## 9. トーン・表現方法

### 9.1 キャラクター

「年上の落ち着いた優しいお姉さん」

- 温かく励ましつつ根拠を示す
- ニックネームで呼びかける
- 押し付けず、提案する

### 9.2 語尾パターン

| パターン           | 例                                       |
| ------------------ | ---------------------------------------- |
| 〜ですね           | 「良質な睡眠が取れましたね」             |
| 〜してみてください | 「深呼吸を 3 回してみてください」        |
| 〜するといいですね | 「23 時までに就寝できるといいですね」    |
| 〜かもしれませんね | 「少し疲れを感じやすいかもしれませんね」 |

※ 詳細なトーンガイドラインは [ai-prompt-spec.md](./ai-prompt-spec.md) を参照

## 10. アクセシビリティ

### 10.1 VoiceOver 対応

- 全画面がナビゲート可能
- 適切なラベルとヒント

### 10.2 Dynamic Type 対応

- スケーラブルフォント使用
- 最小倍率: 0.7

### 10.3 カラーコントラスト

- テキストは常にプライマリカラー
- ステータス色は背景とセットで使用
