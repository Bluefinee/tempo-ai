## 1. デザイン哲学

### 1.1 コンセプト

| 原則 | 説明 |
|------|------|
| **Calm Technology** | 1日1回の穏やかなアドバイス。押し付けない |
| **Data as Poetry** | 数値を「波」「リズム」のような詩的ビジュアルで表現 |
| **Personal Rhythm** | 他人との比較なし。過去の自分との対話 |

### 1.2 デザインリファレンス

| アプリ | 参考ポイント |
|--------|-------------|
| Athlytic | スコアカード、Health詳細、グラフ表示 |
| Apple Health | 明快さ、データの視認性 |
| Headspace | 温かみ、親しみやすさ |
| Oura | データ可視化、スコア表示 |
| Structured | 色のコントラスト、構造的な明快さ |

## 2. デザインシステム

### 2.1 カラーパレット

| 名前 | 色コード | 用途 |
|------|---------|------|
| Recovery Green | `#22C55E` | Recovery、正常範囲内 |
| Sleep Indigo | `#6366F1` | Sleep、インディゴ系 |
| Rhythm Purple | `#A855F7` | Rhythm |
| Energy Amber | `#F59E0B` | Energy、Steps |
| Coral | `#F87171` | RHR、範囲外警告 |
| Teal | `#14B8A6` | SpO2 |
| Blue | `#3B82F6` | Respiratory |
| Off-White | `#FAFAF9` | 背景（ライト） |
| Deep Navy | `#0F172A` | 背景（ダーク、Breathe画面） |
| Text Primary | `#1C1917` | メインテキスト |
| Text Secondary | `#78716C` | サブテキスト |

### 2.2 ステータスカラー

| ステータス | 色 | アイコン | 用途 |
|-----------|-----|---------|------|
| Within Range | Green `#22C55E` | ✓ チェックマーク | 正常範囲内 |
| Out of Range | Orange `#F97316` | + プラス | 範囲外（High/Low） |

### 2.3 タイポグラフィ

| 用途 | フォント | サイズ |
|------|---------|--------|
| 大見出し | SF Pro Display Bold | 28-32px |
| 見出し | SF Pro Display Semibold | 24px |
| セクションヘッダー | SF Pro Display Semibold | 14px, uppercase |
| 本文 | SF Pro Text Regular | 16px |
| キャプション | SF Pro Text Regular | 14px |
| 大きな数値 | SF Pro Rounded Bold | 48-72px |
| カード内数値 | SF Pro Rounded Semibold | 32-40px |

### 2.4 スペーシング

8pxグリッドシステム。

| サイズ | 値 | 用途 |
|--------|-----|------|
| xs | 4px | 最小マージン |
| sm | 8px | コンパクトな間隔 |
| md | 16px | 標準マージン |
| lg | 24px | セクション間、画面パディング |
| xl | 32px | 大きな区切り |

### 2.5 カード・シャドウ

| 要素 | 角丸 | シャドウ |
|------|------|---------|
| スコアカード | 16px | `0 2px 8px rgba(0,0,0,0.06)` |
| セクションカード | 16px | `0 4px 12px rgba(0,0,0,0.06)` |
| ボタン | 12px | なし |
| チャートカード | 16px | 軽微 |

### 2.6 アクセントボーダー

セクションヘッダーに左側4pxのカラーボーダーを使用。

### 4.7 Rhythm画面

| 要素 | 説明 |
|------|------|
| タイトル | "あなたの体内時計" + サブタイトル |
| エネルギーグラフ | 1日の曲線、現在地表示、Peak/Dipラベル |
| UPCOMING WINDOWS | Peak Focus、Wind Downカード（カラーボーダー付き） |
| ENVIRONMENTAL DATA | 環境データセクション（2列×3行グリッド） |

#### Environmental Dataセクション

| カード | アイコン | 表示内容 |
|--------|---------|---------|
| Sunrise | 🌅 | 日の出時刻（例: 6:50） |
| Sunset | 🌇 | 日の入り時刻（例: 16:48） |
| Weather | ☁️ | 天気状態 + 気温（例: 晴れ 8°C） |
| Pressure | ⚙️ | 気圧 + トレンド（例: 1018 hPa ↑上昇中） |
| UV Index | ☀️ | UV指数 + レベル（例: 3 中程度） |
| Moon Phase | 🌙 | 月齢 + 輝面比（例: 上弦の月 48%） |
