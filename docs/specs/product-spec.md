# Tempo AI プロダクト仕様書

**バージョン**: 6.0
**最終更新日**: 2025 年 12 月 31 日

---

## 1. プロダクト概要

### 1.1 コンセプト

**「自分のテンポで、健やかな毎日を」**

Tempo AI は、HealthKit データと気象・環境データを AI が分析し、**その日の過ごし方**をパーソナライズしてアドバイスするヘルスケアアプリです。

### 1.2 ターゲットユーザー

- 健康意識があり、データに基づくヘルスケアに興味がある
- Apple Watch または iPhone でヘルスケアデータを記録している

### 1.3 重要な制約

**医学的なアドバイス・診断は絶対に行わない**

## 3. 機能要件

### 3.1 エネルギーバッテリー表示

**目的**: ユーザーが「今日は無理していい日か、休むべき日か」を 0.1 秒で判断できるようにする

| 要素             | 内容                                    |
| ---------------- | --------------------------------------- |
| エネルギー値     | HRV スコア（0-100）をパーセント表示     |
| プログレスバー   | スコアに応じた塗りつぶしゲージ          |
| AI コメント      | スコアに応じた一言コメント              |

※ UI 詳細は [ui-spec.md](./ui-spec.md) セクション 4.2 を参照

### 3.2 メインアドバイス機能

#### 生成タイミング

| 条件                     | 動作                   |
| ------------------------ | ---------------------- |
| その日初めてアプリを起動 | アドバイスを新規生成   |
| 同日中に再度起動         | キャッシュを表示       |
| オフライン時             | 前日のアドバイスを表示 |

#### アドバイスの構成要素

| セクション                       | 長さ目安                           |
| -------------------------------- | ---------------------------------- |
| 挨拶                             | 1 文                               |
| **エネルギーコメント**           | 10-20 文字                         |
| コンディション概要（ホーム用）   | 3-4 文                             |
| コンディション詳細（詳細画面用） | 8-12 文                            |
| 今日のトライ                     | タイトル 15 文字以内 + 詳細 3-5 文 |
| お見送りメッセージ               | 1-2 文                             |

※ 詳細な出力形式は [ai-prompt-spec.md](./ai-prompt-spec.md) を参照

### 3.3 今日のトライ機能

| 項目           | 内容                             |
| -------------- | -------------------------------- |
| 難易度         | 低（5-15 分で完結）              |
| 多様性         | 過去 2 週間と重複しない          |
| パーソナライズ | 「なぜ今日これなのか」を必ず明示 |

### 3.4 関心ごとタグ機能

**6 カテゴリー**: エネルギー、栄養、運動、メンタル、美容、睡眠

| 項目           | 内容                     |
| -------------- | ------------------------ |
| 選択数         | 1〜3 個（必須）          |
| 設定タイミング | 初回オンボーディング時   |
| 変更           | 設定画面からいつでも可能 |

## 4. サーカディアンリズム画面

### 4.1 コンセプト: Solar Sync

サーカディアンリズム管理の核心は「体内時計」と「外部時間（太陽）」の**同期（Sync）**です。

24h サークルで「2 つのリズムが重なっているか、ズレているか」を可視化し、
ユーザーが「今、自分の体はどういう状態か」「これから上がるのか下がるのか」を
直感的に把握できるようにします。

### 4.2 画面構成要素

| 要素           | 内容                                               |
| -------------- | -------------------------------------------------- |
| 24h サークル   | 太陽の動き（外周）と体内時計（内周）の同期状態を可視化 |
| 現在地マーカー | 「今」の位置と状態（覚醒/リラックス）を表示        |
| ズレ警告       | 体内時計のズレと改善アクションを提示               |
| 指標リスト     | HRV・睡眠・歩数・日光浴・体温の 5 指標             |
| 今日の見立て   | 因果関係を含む AI コメント                         |

### 4.3 指標の因果関係

```
日光浴（原因・アクション）
    ↓ 体内時計をリセット
体温リズム（位相）
    ↓ 睡眠の質に影響
睡眠（結果・回復）
    ↓ 自律神経の回復
HRV（結果・状態）
    ↑
歩数（活動）── 適度な活動が睡眠を促進
```

### 4.4 各指標の役割

| 指標   | 役割           | 説明                                       |
| ------ | -------------- | ------------------------------------------ |
| HRV    | 結果           | 今日の自律神経の状態                       |
| 睡眠   | 結果           | 昨夜の回復度                               |
| 歩数   | 活動           | 日中の活動量                               |
| 日光浴 | 原因（重要）   | リズムを整える唯一の能動的アクション       |
| 体温   | 位相           | 体内時計のズレを検出                       |

**日光浴が最重要**: 「光を浴びる」という行動だけが、体内時計を能動的にリセットできます。
他の指標は「結果」を示すのに対し、日光浴は「原因」を示す唯一の指標です。

### 4.5 マイ・ルーティン機能

ユーザーが日々の習慣をチェックリストで管理できる機能。

| 項目           | 内容                                     |
| -------------- | ---------------------------------------- |
| ルーティン登録 | ユーザーが自分の習慣を登録               |
| 日次チェック   | 今日達成した習慣をチェック               |
| データ保存     | ローカルに保存（将来的に API 連携も検討）|

### 4.6 詳細画面（v1.1 予定）

MVP では詳細画面なし（1 画面完結）。
v1.1 で「あなたのパターン」（散布図）と一緒に各指標の詳細画面を実装予定。

※ UI 詳細は [ui-spec.md](./ui-spec.md) セクション 5 を参照
※ スコア算出は [metrics-spec.md](./metrics-spec.md) を参照

## 5. データ要件

### 5.1 HealthKit（必須）

| データ種別   | 用途                   |
| ------------ | ---------------------- |
| HRV          | 自律神経バランス評価   |
| 睡眠分析     | 睡眠時間、睡眠ステージ |
| 歩数         | 活動量評価             |
| 安静時心拍数 | 回復度評価             |

### 5.2 環境データ

| データ種別       | 用途               |
| ---------------- | ------------------ |
| 気温・湿度・気圧 | 体調への影響評価   |
| 天気・UV 指数    | 外出アドバイス     |
| AQI・PM2.5       | 大気汚染アドバイス |

### 5.3 補助データ（任意）

| データ種別 | 対応機種 | 用途 |
|------------|----------|------|
| 日光浴時間 | watchOS 10+ | 睡眠の質に影響する光曝露を把握、因果関係の説明に活用 |
| 皮膚温 | Apple Watch Series 8+/Ultra | 体内時計の位相ズレを検出、リズム異常の説明に活用 |

**活用方針**:
- 取得できる場合のみ収集（対応機種を持たないユーザーには影響なし）
- UIには主要メトリクスの補足情報として表示
- AIが因果関係を説明する際に活用（良い時/悪い時に「なぜそうなったのか」を補足説明）

## 6. オンボーディングフロー

1. ウェルカム画面
2. ニックネーム入力（必須）
3. 基本情報入力（年齢・性別・体重・身長）
4. 職業・生活習慣（任意）
5. 関心ごとタグ選択（1-3 個、必須）
6. 権限リクエスト（HealthKit・位置情報）
7. データ取得中
8. ホーム画面

---

## 7. エラーハンドリング

| エラーケース         | 対応                                |
| -------------------- | ----------------------------------- |
| オフライン           | 前日のアドバイス表示                |
| HealthKit データ不足 | 一般的なアドバイス + 説明メッセージ |
| 気象データ取得失敗   | 気象関連を省略して生成              |
| Claude API エラー    | フォールバックアドバイス表示        |
| 位置情報取得失敗     | 都市手動選択ダイアログ              |

※ エラー画面 UI は [ui-spec.md](./ui-spec.md) セクション 7 を参照

## 8. プライバシー

| 原則           | 内容                             |
| -------------- | -------------------------------- |
| データ最小化   | 必要最小限のみ取得               |
| デバイス内処理 | HealthKit データはデバイス内のみ |
| 匿名化         | AI 送信時は個人識別情報を除外    |

## 9. MVP スコープ

### 含まれる機能

- オンボーディング
- HealthKit 基本データ取得
- 気象・大気汚染データ統合
- **エネルギーバッテリー表示**（HRV スコア + AI コメント）
- 毎朝のメインアドバイス生成
- 今日のトライ提案
- サーカディアンリズム画面（**現在時刻カーソル + ゾーン色分け**）
- **因果関係を明示した AI の見立て**
- **補助データによる因果関係説明**（日光浴時間・皮膚温を活用したinsight生成）
- **マイ・ルーティン機能**（ユーザー登録習慣のチェックリスト）
- 設定画面

### v1.1 以降に延期

- 詳細画面（散布図 + ヒント）
- プッシュ通知
- 過去のアドバイス履歴
- ダークモード
- マイ・ルーティンとAI連携
