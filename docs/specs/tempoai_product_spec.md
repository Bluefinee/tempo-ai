## 1. プロダクト概要

### アプリ名
**TempoAI**

### コンセプト
**"Tune Your Rhythm"**

人それぞれ異なる「固有のテンポ（自律神経・体内時計）」を整え、日々のパフォーマンスを最適化するAIパートナー。

### コアバリュー

| バリュー | 説明 |
|---------|------|
| **Understanding** | 自分の今の「テンポ」を数値と言語で理解する |
| **Alignment** | 気象や環境の変化に対し、事前に備える |
| **Simplicity** | 複雑な管理を排し、今の状態を直感的に把握する |
| **Action** | 状態を知るだけでなく、その場で「整える」手段を提供する |

### 設計思想

**データベースレス × ヘルスデータ × 生成AI**

- プライバシー重視: ヘルスケアデータは端末内完結
- 軽量設計: サーバーはAI連携のプロキシのみ
- ミニマリズム: タイムラインを排除し「今」に集中
- クロスプラットフォーム: iOS / Android 両対応

#### HealthKitからの自動推定

**クロノタイプ（朝型/中間型/夜型）**:
- 過去30日の睡眠データから**MSFsc（睡眠中間点）**を算出
- MSFsc = (平均就寝時刻 + 平均睡眠時間/2) で計算
- MSFsc < 3:00 → 朝型、3:00-5:00 → 中間型、> 5:00 → 夜型
- UIでは「あなたは○○型のようです。合っていますか？」と確認

**目標就寝時刻**:
- 過去30日の平均就寝時刻を算出
- 「あなたの平均就寝時刻は23:30です。これを目標にしますか？」と提案
- ユーザーが調整可能

### 2.3 キャリブレーション期間（最初の7日間）

**目的**: HRVのベースラインやリズムの標準偏差を正確に計算するためのデータ蓄積期間。

**UI表示**:
- スコアは「---」と表示（数値を出さない）
- 代わりに「あなたのリズムを学習中... あと○日」のプログレスバー
- AI Daily Insightはコメント主体（スコア言及なし）

**完了条件**:
- 7日間のHealthKitデータが蓄積
- または、過去30日のデータが既に存在する場合はスキップ

#### A. AI Daily Insight

アプリの**最重要機能**。毎朝1回、Claudeが生成するパーソナライズされた分析とアドバイス。

**カード表示（ホーム画面）:**
- タイトルなし、直接メッセージから始まる
- 要約（3-4文）を表示
- 「続きを読む」ボタンで詳細へ

**ローディング演出（Labor Illusion）:**
- 「睡眠データを解析中...」
- 「自律神経バランスを計算中...」
- 「今日の環境を確認中...」
- 「あなたへのアドバイスを作成中...」

#### B. Morning Check-in

主観データと今日の予定を入力。

**気分（Mood）**: ワンタップで5段階の気分を記録
- シンプルな顔アイコン（モノクロ/ミニマル）
- 客観データ（HRV等）と主観の乖離を検出

**今日のモード（Today Mode）**: 3択で今日の予定を入力
- **通常**: 普段通りの1日
- **頑張る日**: 重要な会議やプレゼンがある日 → AIは午前中に集中力を高める提案
- **休日**: リラックス優先の日 → AIは回復重視の提案

#### C. Scores

3つのスコアをシンプルアイコン＋数値で表示。

| スコア | アイコン | 評価対象 |
|--------|---------|---------|
| 自律神経 | ♡ | HRVベースの回復状態 |
| 睡眠 | ☽ | 睡眠の質と量 |
| リズム | ◎ | 就寝・起床の規則性 |

**キャリブレーション期間中の表示**:
- 数値の代わりに「---」を表示
- 「学習中」のラベル

> 算出ロジックは [tempoai_metrics_spec.md](./tempoai_metrics_spec.md) 参照

#### D. Circadian Clock

24時間サークルで「今」の位置と推奨モードを表示。

- 🔥 活動ゾーン: 交感神経優位の時間帯
- 🌙 休息ゾーン: 副交感神経優位の時間帯
- ユーザーのクロノタイプに応じてパーソナライズ

#### E. Environment

気象・環境情報のミニカード。

- 気温、気圧（傾向: ↑↓→）、UV指数
- 体調への影響をAIが考慮

#### F. Quick Action

スコアやAI提案に基づいて表示される即時アクション。

- **深呼吸ガイド**: 1分間、Haptics振動でガイド
- **朝の光リマインダー**: 起床後30分以内に通知

## 3. データソース

### HealthKit

| データ | 用途 |
|--------|------|
| HRV | 自律神経スコア |
| 睡眠ステージ | 睡眠スコア、リズム分析 |
| 安静時心拍数 | コンディション補正 |
| 歩数 | 活動スコア |
| 日光暴露時間 | リズム分析（対応機種） |

| データ | 用途 |

| 天気 | UI |
|------|-----|
| 晴れ | 明るく爽やか |
| 曇り | ニュートラル |
| 雨 | しっとり落ち着いた色調 |

### レイテンシ対策

**即時表示戦略:**
- 起動時: 前回アドバイスをキャッシュから即座に表示
- スコア: ローカル計算のため即座に表示
- AI生成: ストリーミングでリアルタイム表示

**バックグラウンドプリフェッチ:**
- iOS Background App Refreshを活用
- 起床予定時刻の1時間前にサイレントでAI生成を開始
- 起床時にはキャッシュ済みのInsightを即座に表示

**オフライン/エラー時のフォールバック:**
- スコア: ローカル計算のため常に表示可能
- AI Insight: 通信エラー時は定型アドバイス（ローカル生成）を表示
- 「ネットワーク接続時に詳細な分析を更新します」のメッセージ

**ローディング演出:**
- 400ms以上かかる場合のみローディング表示（Doherty Threshold）
- 「分析中...」ではなく具体的なステップを表示（Labor Illusion）

## 5. ユーザーフロー

### 毎朝の典型フロー

```
1. アプリ起動
   ↓
2. AI Daily Insight を読む（要約→詳細）
   ↓
3. Mood Check-in（任意）
   ↓
4. スコアとCircadian Clockを確認
   ↓
5. Quick Actionを実行（任意）
   ↓
6. 1日を過ごす
```

### 週次の振り返りフロー

```
1. Analytics タブを開く
   ↓
2. 週間トレンドを確認
   ↓
3. Rhythm Consistency をチェック
   ↓
4. Insights から改善ポイントを把握
```
