## 1. デザイン哲学

### 1.1 コンセプト

| 原則 | 説明 |
|------|------|
| **Calm Technology** | 1日1回の穏やかなアドバイス。押し付けない |
| **Data as Poetry** | 数値を「波」「リズム」のような詩的ビジュアルで表現 |
| **Personal Rhythm** | 他人との比較なし。過去の自分との対話 |

### 1.2 デザインリファレンス

| アプリ | 参考ポイント |
|--------|-------------|
| Apple Health | 明快さ、データの視認性 |
| Headspace | 温かみ、親しみやすさ |
| Oura | データ可視化、スコア表示 |
| Muji | 余白、ミニマリズム |
| Structured | 色のコントラスト、構造的な明快さ |

## 3. 画面構成

### 3.1 タブバー

| タブ | アイコン | 特徴 |
|------|---------|------|
| Today | Home | - |
| Rhythm | Chart line | - |
| Breathe | Wave | 中央配置、浮き出しデザイン |
| Insights | Lightbulb | - |
| Settings | Gear | - |

Breatheタブは中央に配置し、他のタブより大きく、背景色付きで目立たせる。

### 3.2 Today画面

| 要素 | 説明 |
|------|------|
| 日付ナビゲーション | 左右矢印で日付切替、タップでカレンダー |
| 挨拶 | 時間帯に応じた挨拶（Good Morning等） |
| Tempo Score | 波のアニメーション付き円形スコア |
| AIメッセージカード | タイトル + 本文 + Related Insight |
| Today's One Thing | アクション提案カード |
| メトリクスピル | Sleep / HRV / Steps（タップでボトムシート） |

### 3.3 ボトムシート（Sleep / HRV / Steps）

| 要素 | 説明 |
|------|------|
| ドラッグハンドル | 上部中央 |
| CURRENT STATUS | 大きな数値 + ベースライン比較 |
| バーグラフ | 直近12時間の推移 |
| Tempo Insight | AIによる詳細分析 |
| サブメトリクス | 3つの補助指標 |

各ボトムシートはメトリクス固有のカラーをアクセントに使用。

### 3.4 Rhythm画面

| 要素 | 説明 |
|------|------|
| タイトル | "Your Rhythm" + サブタイトル |
| エネルギーグラフ | 1日の曲線、現在地表示 |
| フェーズラベル | Peak Focus, Afternoon Dip等 |
| UPCOMING WINDOWS | 次のフェーズ一覧 |
| Sunrise / Sunset | 日の出・日の入り時刻 |

### 3.5 Breathe画面

| 要素 | 説明 |
|------|------|
| 背景 | Deep Navy（没入型） |
| 呼吸円 | グロー効果付き、膨張・収縮アニメーション |
| 指示テキスト | "Inhale..." / "Hold..." / "Exhale..." |
| タイマー | 経過時間（MM:SS） |
| 一時停止ボタン | 白い円形ボタン |

### 3.6 Insights画面

| 要素 | 説明 |
|------|------|
| 週間バーグラフ | 曜日ラベル付き、今日を強調 |
| TOP DISCOVERY | インディゴ背景のハイライトカード |
| RECENT ALERTS | アラートリスト（アイコン + 説明 + 日付） |

### 3.7 Settings画面

| セクション | 項目 |
|-----------|------|
| プロフィール | アバター、名前、プラン |
| MY RHYTHM | Target Bedtime, Target Wake Up |
| PREFERENCES | Gentle Nudges, Haptic Feedback |
| DATA SOURCE | Apple Health, Oura Ring |
| SUPPORT | Help Center, Privacy Policy |

## 4. オンボーディング

### 4.1 フロー（5画面）

| # | 画面 | 内容 |
|---|------|------|
| 1 | Welcome | ロゴ + タグライン + CTA |
| 2 | Goal Selection | 4つの目標から複数選択 |
| 3 | Schedule | 起床・就寝目標の設定 |
| 4 | Health Connect | HealthKit連携説明 + CTA |
| 5 | Ready | 完了 + 7日間学習の説明 |

### 4.2 デザインガイドライン

- 絵文字を使用しない
- 長文を避ける（見出し2-4語、本文1-2文）
- 余白を十分に取る
- 落ち着いた、洗練されたトーン

## 5. インタラクション

### 5.1 アニメーション

| 要素 | デュレーション | イージング |
|------|--------------|-----------|
| 画面遷移 | 300ms | ease-in-out |
| ボトムシート | 350ms | spring |
| Tempo Score波 | 4秒周期 | ease-in-out |
| 呼吸円 | 4-7-8秒 | spring |

### 5.2 Haptic Feedback

| アクション | フィードバック |
|-----------|---------------|
| タップ | Light |
| 呼吸開始 | Medium |
| 完了 | Success |
