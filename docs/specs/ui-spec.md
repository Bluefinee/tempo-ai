## 1. デザイン原則

### 1.1 TempoAI 固有の原則

| 原則 | 実践方法 |
|------|---------|
| 情報の優先順位を明確に | ホーム画面では「AI Daily Insight」を最優先 |
| データを「感じさせる」 | スコアだけでなく状態を言葉で表現 |
| 押し付けない、寄り添う | 「〜してみてください」という柔らかい語尾 |
| 今に集中 | タイムラインを排除し「今の状態」にフォーカス |

### 1.2 適用する UX 心理原則

- **Doherty Threshold**: 0.4秒以内の反応
- **Labor Illusion**: AI分析中を明示し価値を感じさせる
- **Progressive Disclosure**: 詳細は「続きを読む」で展開

## 3. アイコンシステム

### 3.1 デザイン原則

TempoAIでは**モノクロ/ミニマル**なアイコンを使用し、落ち着いた雰囲気を演出。

- カラフルな絵文字は使用しない
- シンプルな線画またはシンボルを使用
- SF Symbolsを優先的に使用

## 6. インタラクション

### 5.1 画面遷移

| 遷移の種類 | アニメーション |
|-----------|--------------|
| 詳細画面への遷移 | 右からスライドイン |
| 戻る動作 | 左へスライドアウト |
| モーダル表示 | 下からスライドアップ |

### 5.2 タップフィードバック

| 要素 | フィードバック |
|------|--------------|
| ボタン | タップ時に色が少し濃くなる |
| カード | タップ時に少し縮む（scale: 0.97） |
| 応答速度 | 0.4秒以内 |

### 5.3 ローディング

- 表示タイミング: APIリクエスト開始から400ms後（Doherty Threshold）
- スタイル: システム標準スピナー + テキスト（「分析中...」）

### 5.4 アプリの「鼓動」

背景色がHRVに合わせてゆっくり明滅（Breathing効果）。

## 7. トーン・表現方法

### 6.1 キャラクター

「年上の落ち着いた優しいお姉さん」

- 温かく励ましつつ根拠を示す
- ニックネームで呼びかける
- 押し付けず、提案する

### 6.2 語尾パターン

| パターン | 例 |
|---------|-----|
| 〜ですね | 「良質な睡眠が取れましたね」 |
| 〜してみてください | 「深呼吸を1分間してみてください」 |
| 〜するといいですね | 「23時までに就寝できるといいですね」 |
| 〜かもしれませんね | 「少し疲れを感じやすいかもしれませんね」 |

※ 詳細は [ai-prompt-spec.md](./ai-prompt-spec.md) を参照

## 8. アクセシビリティ

### 7.1 VoiceOver 対応

- 全画面がナビゲート可能
- 適切なラベルとヒント

### 7.2 Dynamic Type 対応

- スケーラブルフォント使用
- 最小倍率: 0.7

### 7.3 カラーコントラスト

- テキストは常にプライマリカラー
- ステータス色は背景とセットで使用
- WCAG 2.1 AA基準を満たすコントラスト比
